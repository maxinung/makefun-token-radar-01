How the value is computed

implied value = TVL × peer multiple × growth × age × chains

  • Peer multiple: the median mcap/TVL of the tokened protocols in the same category (only peers with a positive market cap and TVL count). A category with fewer than 3 qualifying peers uses the global median instead, so no single peer can set a category’s price.
  • Growth: 1 + clamp(7-day TVL change, −50%, +100%) / 200. A week’s momentum, capped so one wild week cannot 45× a value.
  • Age: 0.85 + 0.15 × min(days since listing, 1500) / 1500. A longer record earns a fuller multiple.
  • Chains: 1 + 0.03 × min(chains − 1, 10). Broader reach earns a little more.
  • Eligibility: a protocol ranks only if it records no token and is not a wrapped, staked or bridged product, a versioned deployment, a CEX, or an exchange’s own product. The snapshot’s watchlist rule, applied to every row.
